# CodSoft Data Science Internship – Week 2

## Sales Data Analysis & Dashboard

This project was completed as part of the CodSoft Data Science Internship.

### Tools & Technologies
- Python
- Pandas
- Matplotlib
- Power BI
- Google Colab
- Kaggle Dataset

### Project Objectives
- Clean and explore sales data
- Handle missing and duplicate data
- Calculate important sales KPIs
- Analyze product categories
- Analyze regional performance
- Analyze customer segments
- Analyze payment methods
- Analyze monthly sales trends
- Identify top-selling products
- Create an interactive Power BI dashboard

### Key KPIs
| KPI | Value |
|---|---:|
| Total Sales | 484,559.34 |
| Total Profit | 158,872.32 |
| Total Orders | 2,000 |
| Total Quantity Sold | 7,115 |
| Total Customers | 1,534 |
| Average Order Value | 242.28 |

### Key Insights
- Furniture generated the highest sales and profit among product categories.
- Technology had the highest quantity sold.
- Consumer customers generated the highest sales.
- Credit Card transactions generated the highest sales among payment methods.
- Mexico recorded the highest sales and profit among the countries analyzed.
